# コサイン類似度で「あなたに合うコーヒー」を提案するアプリを作った

## 何を作ったか

CafeNavi——味の好みに答えるだけで、25種のコーヒー豆からベストマッチを提案するWebアプリ。サーバーレスで、すべての処理がブラウザ内で完結する。

デモ: https://ryo722.github.io/CafeNavi/

## マッチングの仕組み

コーヒー豆の味を数値化するところから始めた。

各豆に10軸のフレーバースコアを定義した。苦味、酸味、甘み、ボディ、フルーティさ、フローラル、ナッティ、チョコレート、ロースト、クリーンネス。25種の豆それぞれに0〜10の数値を設定し、987行のプロファイルデータを作った。

ユーザーの回答もスライダーで同じ10軸に変換する。初心者モードは10問でわかりやすい表現、中級者モードは20問でフローラルやナッティ感など細かい軸まで聞く。

マッチングにはコサイン類似度を使った。ユーザーの好みベクトルと各豆のフレーバーベクトルの角度を計算し、最も近い豆を提案する。単純なユークリッド距離ではなく、ベクトルの方向を重視したかった。「苦味8・酸味2」と「苦味4・酸味1」は同じ傾向の好みとして扱いたい。

```typescript
// コサイン類似度の計算
const dotProduct = a.reduce((sum, val, i) => sum + val * b[i], 0)
const magnitudeA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0))
const magnitudeB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0))
return dotProduct / (magnitudeA * magnitudeB)
```

## お菓子と飲用シーンの考慮

コーヒーの味だけでなく、ペアリングも考慮に入れた。チョコレート系のお菓子が好きなら、酸味の強い豆より苦味・チョコレート感のある豆が合う。朝に飲むのか、午後のリラックスタイムに飲むのかで、ボディの重さの好みも変わる。

質問にはデザートセレクターとシーンセレクターを組み込み、回答をフレーバースコアの重み付けに反映させた。

## 比較機能

診断結果だけでなく、任意の豆を並べて比較できる機能を作った。レーダーチャートで10軸の違いを視覚的に確認できる。

「エチオピア・イルガチェフェとケニアAA、どちらがフルーティか」がチャートを見れば一目でわかる。逆引き的な使い方を想定した。

## 統計ダッシュボード

診断結果はLocalStorageに保存される。回を重ねるごとに、自分の味覚傾向がトレンドチャートで可視化される。

8つの味覚タイプ分類も実装した。フルーティ派、ビター派、チョコナッツ派、フローラル派、ヘビーボディ派、スイート派、クリーン派、バランス派。診断を繰り返すと、自分がどのタイプに属するかが見えてくる。

## テスト

ユニットテスト68件、E2Eテスト14件。

スコアリングロジック、コサイン類似度計算、味覚タイプ分類、ストレージ操作をVitest でカバーした。Playwright E2E テストでは、診断フロー全体の動作、豆比較のインタラクション、ナビゲーション、ガイドページの表示を検証した。

マッチングの正確性はデータ次第なので、プロファイルデータ自体のバリデーションテストも書いた。全25豆のスコアが0〜10の範囲にあるか、必須フィールドが欠けていないかを自動チェックする。

## 技術スタック

React 19 + TypeScript + Vite + Tailwind CSS 4。ポートフォリオサイトと同じ構成にした。慣れた環境で素早く作りたかった。

多言語対応はReact Context + 手書き翻訳で実装。i18nライブラリは入れなかった。この規模なら手書きのほうが依存が少なくて済む。

ダーク/ライトテーマはシステム設定に追従。Tailwind CSSのダークモードをそのまま使った。

## 振り返り

25種の豆プロファイルを作るのが一番時間がかかった。各豆の産地特性、焙煎度による味の変化、一般的なカッピング評価を調べて数値化する作業だ。ここはドメイン知識の世界で、コードを書くより調査の比重が大きかった。

アルゴリズム自体はシンプルだが、「質問の聞き方」と「フレーバースコアへの変換」の設計が診断結果の品質を左右する。10軸のうちどの軸をどの質問で測るか、1つの質問が複数軸に影響する場合の重み配分——この部分はAIと壁打ちしながら調整した。

コード行数は9,191行。うちデータ定義が約2,000行を占める。ロジックよりデータが多いアプリだ。
