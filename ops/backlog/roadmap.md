## BL-A: ESLint ルール強化

**現状**: `@eslint/js` recommended + `typescript-eslint` recommended + `no-console: warn`。lint PASS。
**着手条件**: テスト基盤安定後の空き時間（Phase 2完了済みなので、いつでも着手可能）
**優先度**: 低
**想定工数**: 30分〜1時間（既存エラー数に依存）
**依存関係**: なし
**完了条件**: `typescript-eslint/strict` 適用 + 既存コード修正 + CI PASS
**今やらない理由**: recommended で実害なし。大規模改善の合間に差し込む

## BL-B: 残り6プロジェクトのスクリーンショット

**背景**: 9プロジェクト中3件のみ画像あり。画像なし6件はアイコン表示で見劣りする。
**現状**: DuelMastersPlays, DMOriginalCardGenerator, EVPanel8 の3件完了。
**着手条件**: 各プロジェクトがローカル起動可能であること
**優先度**: 中
**想定工数**: 1-2時間（環境構築時間除く）
**依存関係**: 各プロジェクトの開発環境
**完了条件**: 全9プロジェクトに画像設定 + `src/data/projects.ts` 更新
**進捗**: フォールバック表示を改善済み（カテゴリアイコン + カテゴリ名 + 技術スタック3つ）。実画像追加は各プロジェクト起動時に随時対応。
**今やらない理由**: 6件すべてがDB依存/リモート/Unity環境等でローカル起動困難。フォールバック改善で品質差を縮小済み。

**対象と方法**:
| プロジェクト | 方法 | 優先度 |
|---|---|---|
| M4FX | Streamlit UIをローカル起動 | 高 |
| SNS自動投稿 | Next.js管理画面をローカル起動 | 中 |
| マルチエージェントOS | 概念図を作成 | 中 |
| ゼロトラスト自宅サーバー | 構成図を作成 | 中 |
| ポケカダメージ | Unity起動（環境依存大） | 低 |
| Notion日記自動化 | ターミナル出力のスクショ | 低 |

## BL-D: ブログURL構造改善

**背景**: 現在は `.md` ファイルをfetchしてSPA内レンダリング。SEOに不利。
**現状**: 9記事。SPA内表示は正常動作。
**着手条件**: ブログ記事が15本以上 + 検索流入を重視するタイミング
**優先度**: 低（条件未成立）
**想定工数**: 半日〜1日
**依存関係**: React Router導入、GitHub Pages 404ハンドリング
**完了条件**: `/blog/{slug}` のURL構造 + 既存URLからのリダイレクト
**今やらない理由**: 記事9本。SPA内表示で十分機能中。React Router導入は影響範囲大

**ロードマップ**:
1. Stage 1（現状）: SPA内レンダリング — 維持
2. Stage 2（15本到達時）: React Router + HashRouter — 中規模
3. Stage 3（長期）: Next.js移行 or SSG — 大規模
