# ブランドブック — Ryo722 Portfolio

> 上位概念: [portfolio-soul.md](./portfolio-soul.md)（作り手の人間性・トーンの基盤定義）

## コンセプト

「AIと一緒に、アイデアを形にする開発者」

## トーン

| DO | DON'T |
|---|---|
| 事実ベースで書く（テスト数、コミット数等） | 根拠なく「最高」「完璧」と書く |
| 「AIとの共同開発」を自然に表現する | AIに全部やらせている印象を与える |
| 技術的な深さを示す（設計判断、トレードオフ） | 技術名の羅列だけで終わる |
| 謙虚だが自信を持つ | 自信過剰 or 過度に謙遜 |
| 「つくりたいから作った」動機を伝える | 「業務で使った」と偽る |

## 表現ルール

### プロジェクト説明
- 1行目: 何ができるか（ユーザー視点）
- 2行目以降: どう作ったか（技術視点）
- 数値は具体的に（「多くの」→「1,565件の」）

### Private プロジェクト
- 概要と技術スタックは公開可
- ソースコード・内部設計の詳細は非公開
- GitHubリンクは掲載しない

### 禁止表現
- 他者のWebサイト・サービスのスクリーンショットを自作として掲載
- 実在する企業名を許可なく掲載（銀行レポート系は「邦銀」で抽象化）
- 「フルスタック」を自称する際は、実際に構築した層を明示

## ビジュアル

### デザインコンセプト

「無印良品 × ゲームのセーブ画面」
— 余白と素材感で"静かな信頼"を伝えつつ、ステータス表示やカード型UIでゲーム的なワクワク感を演出する。
