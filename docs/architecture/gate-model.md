# 5ゲート品質モデル

すべての公開変更は、Deploy Readiness に到達する前に4つの自動ゲートを通過すること。

## Gate 1: Security Gate

**目的**: 秘密情報の混入防止、依存関係の安全性確認

**チェック項目**:
- [ ] `.env`, APIキー, トークン, パスワードがコミットに含まれていない
- [ ] `git diff` にローカルパス（`/Users/`）が含まれていない
- [ ] 個人情報（メールアドレス以外）がハードコードされていない
- [ ] `npm audit` で critical / high の脆弱性がない

**判定**: 全項目クリアで PASS。1つでも不合格なら BLOCK。

## Gate 2: Performance Gate

**目的**: ビルド成功とバンドルサイズの許容範囲確認

**チェック項目**:
- [ ] `npx tsc --noEmit` が成功する
- [ ] `npm run build` が成功する
- [ ] JS バンドルサイズが 500KB (gzip 150KB) 以下
- [ ] 画像ファイルが各 500KB 以下

**判定**: 全項目クリアで PASS。ビルド失敗は BLOCK。サイズ超過は WARNING。

## Gate 3: Accessibility Gate

**目的**: アクセシビリティの最低基準を満たす

**チェック項目**:
- [ ] `prefers-reduced-motion` 対応済み
- [ ] すべてのインタラクティブ要素がキーボードでアクセス可能
- [ ] 画像に alt 属性がある
- [ ] ボタンに aria-label がある（テキストがない場合）
- [ ] コントラスト比が WCAG AA 基準を満たす

**判定**: 全項目クリアで PASS。

## Gate 4: Brand Gate

**目的**: 公開コンテンツのブランド一貫性と技術的正確性

**チェック項目**:
- [ ] 技術的に不正確な表現がない（根拠のない数値・比較）
- [ ] 他者の成果物を自分のものとして表現していない
- [ ] クライアント・社内情報が含まれていない
- [ ] トーンが一貫している（`docs/architecture/brand-book.md` 準拠）
- [ ] 日本語・英語の両方が更新されている（テキスト変更時）

**判定**: 全項目クリアで PASS。

## Gate 5: Deploy Readiness（人間確認必須）

**目的**: 最終承認

**確認項目**:
- [ ] Gate 1-4 がすべて PASS
- [ ] ローカルプレビューで表示確認済み
- [ ] 変更内容を理解している

**判定**: 人間が承認して PASS。
