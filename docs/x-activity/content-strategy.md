# X活動 コンテンツ戦略

## 目的
ポートフォリオへの導線を作りつつ、開発者としての信頼感を日々の発信で積み上げる。

## KPI（初期フェーズ）
- フォロワー数は追わない（初期は質を優先）
- ポートフォリオサイトへのクリック数を重視
- 1日1ツイート以上を目標（無理なら2日に1回）

## コンテンツミックス

```
開発ログ   40%  — 毎日の作業で自然に出る
技術メモ   30%  — ハマった→解決のペア
AI活用    15%  — Claude Code / LLM系
告知・その他 15%  — ブログ・PR・感想
```

## 投稿タイミング
- 作業の区切り（コミット後、デプロイ後）
- 問題解決直後（記憶が新鮮なうちに）
- ブログ記事公開時

## ポートフォリオとの連携

| X投稿 | ポートフォリオ |
|---|---|
| 開発ログ（短文） | → ブログ記事（長文）への導線 |
| 技術メモ（断片） | → プロジェクト詳細への導線 |
| PR提出報告 | → OSSコントリビュート記事への導線 |

**原則**: Xで興味を引き、ポートフォリオで詳細を見せる。

## スレッド活用
長い技術トピックは1ツイートに収めず、スレッドで展開する。

```
1/ [タイトル + 概要]
2/ [問題の説明]
3/ [解決策]
4/ [結果 + リンク]
```

## ハッシュタグ方針
- 毎回つけない（スパム感を避ける）
- つける場合は2-3個まで
- 候補: #個人開発 #AIと開発 #TypeScript #React #Python
- 日本語タグ優先（日本語圏のエンジニアが対象）

## 相互交流
- 他の個人開発者のツイートにリアクション・リプライ
- 質問には誠実に回答
- 自分の失敗や学びを共有（完璧な人間を演じない）
