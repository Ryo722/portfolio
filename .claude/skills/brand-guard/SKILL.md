# brand-guard

公開コンテンツのブランド整合性をチェックする。

## トリガー
- テキスト・コンテンツ変更時
- デプロイ前チェック（deploy-checker から呼び出し）

## 参照
- `docs/architecture/portfolio-soul.md`（トーン・人間性の基盤定義）
- `docs/architecture/brand-book.md`

## チェック項目

### 1. 技術的正確性
- 数値に根拠があるか（テスト数、コミット数等は実測値か）
- 「最高」「完璧」「唯一」等の誇張表現がないか
- フレームワーク名・バージョンが正確か

### 2. トーン一貫性
- 「AIとの共同開発」のニュアンスが維持されているか
- 過度に謙遜 or 自信過剰になっていないか
- 日本語と英語で同じ意味が伝わるか

### 3. 情報セキュリティ
- 他者のスクリーンショットを自作として掲載していないか
- 企業名が不必要に露出していないか
- Private プロジェクトのソースコード・内部設計が公開されていないか

### 4. 多言語一貫性
- テキスト変更時、日本語・英語の両方が更新されているか
- `LocalizedText` の `en` フィールドが undefined のまま放置されていないか

## 出力形式

```
## Brand Guard Check
- 技術的正確性: PASS / FAIL (詳細)
- トーン一貫性: PASS / FAIL (詳細)
- 情報セキュリティ: PASS / FAIL (詳細)
- 多言語一貫性: PASS / FAIL (詳細)
- 総合: PASS / FAIL
```
