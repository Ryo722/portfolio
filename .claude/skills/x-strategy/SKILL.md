# x-strategy

X活動の振り返りと投稿テーマの提案を行う。

## トリガー
- `/x-plan` コマンド実行時
- 週次振り返り時

## 実行手順

### Step 1: 直近の開発活動を収集
- `git log --oneline --since="1 week ago"` でコミット履歴
- `ops/logs/devlog/` の最新エントリ
- `ops/backlog/current.md` の進捗

### Step 2: 投稿テーマ候補を生成
直近の活動から、以下のカテゴリで投稿テーマを3-5件提案:

| カテゴリ | テーマの出し方 |
|---|---|
| 開発ログ | 最近のコミットから「何を作った/直した」 |
| 技術メモ | 最近のハマりポイントから「こう解決した」 |
| AI活用 | Claude Codeとの作業から「AIにこう任せた」 |
| 告知 | 新しいブログ記事・PR・リリースから |

### Step 3: 投稿スケジュール案
1週間分の投稿スケジュールを提案:
- 月-金: 開発ログ or 技術メモ（作業中に自然に出る）
- 土日: 振り返り or 学び

### Step 4: コンテンツミックス確認
直近の投稿カテゴリ比率が偏っていないか確認:
- 開発ログ 40% / 技術メモ 30% / AI活用 15% / 告知 15%

## 出力形式

```
## X投稿テーマ提案（YYYY-MM-DD週）

### 開発ログ候補
1. ...
2. ...

### 技術メモ候補
1. ...

### AI活用候補
1. ...

### 告知候補
1. ...

### 推奨スケジュール
- 月: ...
- 火: ...
- ...
```
