# x-reviewer

X投稿の品質をレビューする。

## トリガー
- `x-editor` エージェントからの委任時
- `/x-review` コマンド実行時

## チェック項目（5軸）

### 1. トーン適合
- [ ] `x-voice` のDO/DON'Tに準拠
- [ ] チュートリアル口調、誇張、自虐風自慢がない
- [ ] ブランドコンセプト（過程の共有）に合っている

### 2. 情報密度
- [ ] 1ツイート = 1メッセージになっている
- [ ] 具体性がある（数値、技術名、成果）
- [ ] 曖昧すぎる表現がない

### 3. セキュリティ
- [ ] APIキー、トークン、秘密情報がない
- [ ] ローカルパス、個人情報がない
- [ ] 版権上問題のある言及がない
- [ ] 他者のプライベートリポジトリの情報がない

### 4. 文字数・フォーマット
- [ ] 140字以内（または意図的なスレッド）
- [ ] 改行が適切
- [ ] リンクが正しい
- [ ] ハッシュタグが2個以下

### 5. ポートフォリオ連携
- [ ] 関連するブログ記事やプロジェクトへの導線がある（告知の場合）
- [ ] ポートフォリオの内容と矛盾していない

## 出力形式

```
## X Post Review
- トーン: PASS / REVISE
- 情報密度: PASS / REVISE
- セキュリティ: PASS / FAIL
- フォーマット: PASS / REVISE
- 連携: PASS / N/A

総合: PASS / REVISE
修正提案: {あれば}
```
