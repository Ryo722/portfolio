# daily-ops-log

日次の開発記録を構造化して記録する。

## トリガー
- 作業セッション終了時
- 30分以上の作業完了後

## 実行手順

1. `git log --oneline --since="today"` で本日のコミット一覧を取得
2. 以下のテンプレートで `ops/logs/devlog/YYYY-MM-DD.md` に記録

## テンプレート

```markdown
# DevLog YYYY-MM-DD

## 実施内容
- [ 完了したタスクを箇条書き ]

## コミット
- `hash` message

## 意思決定
- [ 判断が必要だった点と決定内容 ]

## 課題・次回アクション
- [ 残タスク、ブロッカー ]

## メトリクス
- ビルドサイズ: XX KB (gzip XX KB)
- プロジェクト数: N 件
```

## 注意
- 秘密情報を記録しない
- 個人情報を含めない
- 客観的な事実のみ記録
