# x-writer

X投稿を生成する。`x-voice` のトーンを常時適用する。

## トリガー
- `/x-post` コマンド実行時
- `x-editor` エージェントからの委任時

## 入力
- $ARGUMENTS: 投稿のテーマ or 開発ログの内容

## 実行手順

### Step 1: カテゴリ判定
入力内容から以下のカテゴリを判定:
- 開発ログ（作業報告）
- 技術メモ（ハマり→解決）
- AI活用（Claude Code等の実践）
- リリース告知（ブログ・機能公開）
- 学び・感想

### Step 2: 投稿生成
`x-voice` のトーンに従い、以下の制約で生成:

- **文字数**: 140字以内を目標（日本語Xの1ツイート上限は全角140字）
- **構成**: 1メッセージ1ツイート
- **リンク**: 必要な場合のみ末尾に追加
- **ハッシュタグ**: 0-2個

### Step 3: スレッド判定
内容が1ツイートに収まらない場合:
1. 要約版（1ツイート）を生成
2. スレッド版（3-5ツイート）を生成
3. 両方提示して人間に選択を委ねる

### Step 4: セキュリティチェック
- APIキー、トークン、パスワードが含まれていないか
- ローカルパスが含まれていないか
- 版権上問題のある画像・名称への言及がないか

## 出力形式

```
【投稿案】
{本文}

【カテゴリ】 開発ログ / 技術メモ / AI活用 / 告知 / 学び
【文字数】 XX字
【リンク】 あり/なし
【ハッシュタグ】 #xxx #yyy
```

スレッドの場合:
```
【スレッド案】
1/ {1ツイート目}
2/ {2ツイート目}
3/ {3ツイート目}
4/ {リンク}
```

## 常時適用
- `x-voice` スキル（トーン・文体）
- `brand-guard` スキル（ブランド整合性）
