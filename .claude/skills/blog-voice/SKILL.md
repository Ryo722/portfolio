# blog-voice

ポートフォリオブログの文体・トーンを定義する。`blog-writer` 実行時に自動適用される。

user-invocable: false

## トーン定義

### 基本姿勢
- **語り口**: 一人称「私」or 省略。落ち着いた技術者の語り
- **距離感**: 読者と対等。教えるのではなく共有する
- **テンション**: 淡々としつつ、面白かった点は素直に伝える

### DO
- 実装判断の理由を書く（「〜だから〜にした」）
- つまずいた点を正直に書く（失敗→解決のストーリー）
- 具体的な数値で語る（「約」ではなく実測値）
- コード例を添える（短く、要点だけ）
- 「AIと一緒に作った」文脈を自然に含める

### DON'T
- チュートリアル口調（「まず〜しましょう」「次に〜します」）
- 過度な装飾（「驚くべきことに」「なんと」）
- 技術マウント（「当然知っているとは思いますが」）
- 自虐的すぎる表現（「しょぼいですが」「大したことないですが」）
- 宣伝臭（「ぜひ使ってみてください！」）

### 文体ルール
- 一文は60字以内を目安
- 段落は3-5文で改行
- 見出しは体言止めまたは「〜した話」形式
- コードブロックの前後に1行の説明
- 英語の技術用語はそのまま（カタカナ化しない: ×レンダリング→Rendering は可）

### 記事タイプ別トーン

| タイプ | トーン | 例 |
|---|---|---|
| 開発記録 | 日記的・時系列 | 「〜を作った話」 |
| 技術解説 | 構造的・論理的 | 「〜の設計と実装」 |
| 振り返り | 内省的・率直 | 「〜から学んだこと」 |
| ツール紹介 | 実用的・簡潔 | 「〜を使って〜を自動化した」 |
