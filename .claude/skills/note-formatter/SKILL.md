# note-formatter

ブログ記事をnote投稿用フォーマットに変換する。

## トリガー
- `/format-note` コマンド実行時
- `blog-publisher` スキルからの呼び出し時

## 入力
- 記事本文（Markdown）
- 記事メタデータ（title, tags, excerpt）

## 出力フォーマット

```
========================================
【記事タイトル】
========================================
{タイトル}

========================================
【本文】
========================================
{本文（note用に変換済み）}

========================================
【タグ】
========================================
{タグ1}, {タグ2}, {タグ3}, ...

========================================
【追加先マガジン】
========================================
{マガジン名}
```

## 変換ルール

### タイトル
- ポートフォリオ記事のタイトル（日本語）をそのまま使用
- 必要に応じてnote向けに調整（40字以内推奨）

### 本文
1. Markdownからnote互換形式に変換:
   - `## 見出し` → そのまま（noteはMarkdown対応）
   - コードブロック → そのまま（noteはコードブロック対応）
   - 画像リンク → noteの画像挿入に置き換え指示
2. リード文を冒頭に追加（excerpt を利用）
3. 末尾にポートフォリオサイトへのリンクを追加:
   ```
   ---
   この記事の元プロジェクトの詳細はポートフォリオサイトで公開しています。
   https://ryo722.github.io/portfolio/
   ```

### タグ
- 記事の `tags` をカンマ区切りで列挙
- note推奨: 5-10個
- 記事タグに加えて、以下の固定タグを追加:
  - `個人開発`
  - `エンジニア`
  - テーマに応じて: `AI`, `TypeScript`, `React`, `Python`, `インフラ` 等

### 追加先マガジン
- 記事タイプに応じて以下から選定:

| 記事タイプ | マガジン名 |
|---|---|
| 開発記録 | 開発記録 |
| 技術解説 | 技術ノート |
| 振り返り | 開発記録 |
| ツール紹介 | 技術ノート |
| AI関連 | AI × 開発 |

- マガジンが未作成の場合は「（新規作成）」と注記

## 実行手順

1. 入力記事のメタデータと本文を取得
2. タイトルをnote向けに確認（40字以内か）
3. 本文をnote互換形式に変換
4. タグを生成（記事タグ + 固定タグ）
5. 記事タイプからマガジンを選定
6. 4セクション構成のフォーマットで出力

## 注意
- noteの文字数制限なし（ただし読みやすさのため10,000字以内推奨）
- 秘密情報が含まれていないか最終確認
- ポートフォリオ記事と内容の齟齬がないか確認
