# /x-post

X投稿を生成・レビューする。

## 手順
1. `x-writer` でカテゴリ判定 + 投稿生成（`x-voice` 自動適用）
2. `x-reviewer` + `brand-guard` でレビュー
3. PASS なら投稿案を提示
4. REVISE なら修正案を提示
5. 人間が確認して投稿

## 引数
- $ARGUMENTS: テーマ、開発ログの内容、またはブログ記事の告知

## 例
```
/x-post ポートフォリオにシンタックスハイライトを追加した
/x-post ブログ記事公開: ゲームエンジンの話
/x-post torch.loadの互換性問題を解決した
```
